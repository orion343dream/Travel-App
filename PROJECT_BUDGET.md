## Important Notes & Disclaimers

1. **Exchange Rates:** Budget in LKR is based on 1 USD = ₨ 330 (subject to market fluctuation)

2. **Variable Costs:** Actual infrastructure costs depend on:
   - Number of active users
   - Database size and queries
   - File storage requirements
   - API usage

3. **Maintenance Escalation:** Costs may increase in subsequent years based on:
   - New OS versions
   - Third-party API changes
   - Additional features

4. **Marketing ROI:** Marketing costs vary greatly based on target audience and channels

5. **Support Model:** 12-month support includes normal updates; extended support available at additional cost

6. **Payment Processing Fees:** Not included; Khalti/payment gateways charge 2-3% commission on transactions

7. **Revision Clause:** Budget assumes 2-3 rounds of client feedback; additional revisions billed separately
